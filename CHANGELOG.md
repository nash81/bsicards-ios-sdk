# BSICARDS iOS SDK - Changelog

All notable changes to the BSICARDS iOS SDK will be documented in this file.

## [1.0.0] - 2026-03-06

### Added
- Initial release
- Complete MasterCard operations (create, get, freeze, fund, etc.)
- Complete Visa Card operations (create, get, freeze, fund, etc.)
- Complete Digital Wallet operations (create, get, fund, 3DS, loyalty points, etc.)
- Administrator operations (wallet balance, deposits, transactions, card lists)
- Async/await support for modern Swift concurrency
- Full Swift type safety with Codable models
- Comprehensive error handling
- Swift Package Manager support
- Complete documentation and examples
- Unit test framework

### Features
- iOS 13.0+ support
- Swift 5.5+ compatibility
- Type-safe API with Codable models
- Async/await for clean asynchronous code
- Custom error types
- Full Postman collection endpoint coverage
